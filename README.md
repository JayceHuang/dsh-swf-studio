# SWF 场景工坊

DeepSeek Harness 的独立本地插件。提供餐厅、宴会厅常用的 60 款场景预设，按分类或关键词查找，填写中文文字，预览后导出 SWF 动画，并查看文件保存位置。

模板绘制和文件生成都在本机完成，不调用模型、不需要 API Key，也不上传文字。插件以 `.tgz` 安装包单独分发和更新，无需重新打包桌面应用。当前项目尚未声明在插件市场上线。

## 模板与编辑

60 款模板均由本项目绘制，不附带下载的图片或字体素材。预设使用不同的装饰、配色、构图和示例文案；使用前请替换姓名、日期、地点等信息。

| 升学谢师 | 6 | 升学宴、金榜题名、谢师宴 |
| 生日寿宴 | 6 | 生日、成人礼、长辈寿宴 |
| 宝宝成长 | 6 | 满月、百日、周岁、成长纪念 |

| 同学战友 | 4 | 同学会、毕业聚餐、战友相聚 |
| 商务庆典 | 6 | 年会、答谢、开业、签约 |

完整模板名称与预设文案见 [60 款模板目录](docs/templates.md)。已有六款模板的标识与默认颜色保留，之前保存的工程可继续导入。

可编辑主标题、副标题、日期地点、祝福语和文字颜色，选择衬线或无衬线字体。每个文字栏最多 120 个字符，主标题必填。渲染使用当前电脑可用的中文字体，同一工程在不同电脑上的字形和排版可能有差异。

| 时长 | 2–30 秒 |
| 帧率 | 12、24、30 FPS |
| 文字动画 | 淡入淡出、上浮、静态 |

## 使用

1. 在宿主中打开“SWF 场景工坊”，按分类或搜索关键词选择模板。模板分批显示，可点击“加载更多”继续浏览。
2. 修改文字、颜色、字体、画面尺寸和动画设置，查看预览。
3. 导出后查看结果面板中的完整保存路径。
4. 后续修改时导入上次保存的 `project.json`，继续编辑并重新导出。

文件保存在当前用户下载目录下的 `IPZSK-SWF` 文件夹中。每次导出创建独立子文件夹，不覆盖上次作品。常见位置为：

- macOS：`~/Downloads/IPZSK-SWF/`
- Windows：`%USERPROFILE%\Downloads\IPZSK-SWF\`

每次导出包含 SWF 文件和 `project.json`。导出结果如列有 `preview.png`，它是静态预览图。请以结果面板显示的完整路径和文件列表为准。

## 播放与修改

现代浏览器不原生播放 Flash。可以用独立的 [Ruffle 桌面播放器](https://github.com/ruffle-rs/ruffle/releases) 在 macOS 或 Windows 打开 SWF；本插件无需附带播放器。编辑页面的 Canvas 预览用于查看模板效果，实际 SWF 播放应使用播放器验证。

中文文字会固化成 SWF 内的像素图层，播放时不依赖对方电脑的中文字体。需要改字时，导入工程 JSON 重新生成。

当前范围不包含音频、ActionScript 交互、旧 SWF 编辑或 Flash 源工程导入。输出尺寸决定像素清晰度；大屏使用请优先选择与播放设备相符的尺寸。

## 安装与更新

Windows 用户请先阅读 [Windows 安装说明](WINDOWS.md)。GitHub [Releases](https://github.com/JayceHuang/dsh-swf-studio/releases) 提供插件包及包含说明的 Windows 下载包。仓库为私有仓库，下载时需登录有访问权限的 GitHub 账号。

插件源码独立存放在本仓库，版本和发行包独立管理。安装由宿主写入自己的 `profiles/desktop`，无需把源码目录复制进客户端，也无需手动创建插件目录。更新客户端与更新插件是两个操作；本项目尚未接入插件市场自动更新。

需要提供插件客户端注入能力的 DeepSeek Harness 宿主，以及其 `connection`、`slots`、React 和侧栏服务。包内 Node 版本要求为 `>=22.19.0`；安装前应确认宿主运行时满足要求。

**先保存工作并完全退出桌面应用，再安装或更新插件。** 对提供官方 `dsh` 命令的环境，使用本地 `.tgz` 包：

```sh
dsh plugin --profile desktop add /path/to/dsh-swf-studio-0.2.1.tgz
```

安装完成后重新启动桌面应用。更新时安装对应新版本的 `.tgz` 包，再重启宿主。

IPZSK 等品牌桌面应用的命令入口可能不同。请使用该应用支持本地 `.tgz` 的插件管理界面，或随应用提供的 CLI；不要直接套用未经该宿主验证的可执行文件路径。仓库中的安装命令不代表所有品牌桌面版本均已验证。

## 源码构建

在本目录运行：

```sh
pnpm install
pnpm build
pnpm test
pnpm pack
```

生成的 `.tgz` 用于本地安装。`tsdown` 仅用于开发阶段打包；运行时复用宿主服务，SWF 编码使用 Node 内置模块，未引入 sharp、原生 SWF 工具链或模型 SDK。

## 验证范围

项目提供针对场景目录、工程导入导出及 SWF 写入器的自动化测试。结构检查、编辑器预览和实际播放器验证属于不同检查项，不能互相替代。

Windows 设备上的安装、中文字体渲染和 SWF 实际播放尚未完成实机验证。Ruffle 提供 Windows/macOS 发行包，不代表本插件已在这两类设备上完成全流程测试。具体构建的验证结果以交付记录为准。

现有工具的调研、实现选择和 Ruffle 网页验证入口见 [技术调研](docs/research.md)。
